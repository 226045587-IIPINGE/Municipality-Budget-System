# Budget Management Module

~~ Files
> BudgetManagement.c - Contains the implementation of all budget-related functions.
> BudgetManagement.h - Contains the function prototypes so other files can use the module.

## Features
1. Enter departmental budget – Add a new department and set its allocated budget.
2. Enter expenditure – Record spending for an existing department.
3. Display budget information – Shows allocated budget, expenditure, remaining budget, and status (Within / Exceeded).
4. Show departments over budget – List departments that have spent more than their allocated amount.

## How to Use
Include the header in your main program:

  #include "BudgetManagement.h"
